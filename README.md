# Схема регистрации и внедрения Smart GYM в Telegram Mini App (TMA)

Данное руководство описывает пошаговый процесс деплоя и интеграции веб-версии **Smart GYM** в качестве официального Telegram Mini App.

---

## 🏗️ Архитектурная схема интеграции

```
[ Пользователь в Telegram ] 
       │
       ├──► Открывает бота / Кнопку Меню
       │
       ▼
[ HTTPS Хостинг (Vercel / GitHub Pages) ]
       │  (Загружает tma/index.html, app.js, styles.css)
       │
       ▼
[ Telegram WebApp SDK (window.Telegram.WebApp) ]
       │  • Синхронизация темы (Dark/Light)
       │  • Безопасные отступы (Safe Area Insets)
       │
       ▼
[ Локальное офлайн-хранилище (localStorage) ]
       │  • Сохранение активного плана
       │  • Журнал завершенных тренировок
       │  • Авторизация через Gmail
```

---

## 🚀 Пошаговая инструкция по внедрению

### Шаг 1. Подготовка файлов
Все необходимые файлы веб-версии находятся в папке проекта **`tma/`**:
* `index.html` — главная разметка приложения.
* `app.js` — полная бизнес-логика (планы тренировок, ворк-аут трекер, дневник, калькуляторы БЖУ и 1RM).
* `styles.css` — адаптивные стили Material 3 с поддержкой нативных цветов Telegram (`--tg-theme-*`).

### Шаг 2. Размещение на хостинге (Бесплатно через HTTPS)
Для работы Telegram Mini App обязателен защищенный протокол **HTTPS**.
1. Зарегистрируйтесь на **[Vercel](https://vercel.com/)** или **[Netlify](https://www.netlify.com/)** (или используйте **GitHub Pages**).
2. Загрузите папку `tma/` в новый репозиторий GitHub или перетащите её в панель Vercel.
3. Получите публичную HTTPS-ссылку на ваше приложение (например, `https://smart-gym.vercel.app`).

### Шаг 3. Регистрация Mini App через @BotFather
1. Откройте в Telegram официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot` (или выберите существующий бот через `/mybots`).
3. Укажите имя и username бота (например, `SmartGymAppBot`).
4. Задайте мини-приложение командой `/newapp`:
   * Выберите созданного бота.
   * Введите название приложения (например, `Smart GYM`).
   * Введите описание программы.
   * Предоставьте полученную на Шаге 2 HTTPS-ссылку (например, `https://smart-gym.vercel.app`).
   * Загрузите иконку приложения (512x512 px).
5. BotFather выдаст вам прямую ссылку на ваше Mini App вида `https://t.me/SmartGymAppBot/app`.

### Шаг 4. Готово!
Пользователи могут запускать Smart GYM прямо внутри Telegram в один клик. Приложение адаптировано под мобильные экраны, работает автономно и сохраняет всю историю тренировок локально на устройстве.
